# 小四门刷题

福州 · 人教版 · 初中小四门（道德与法治、历史、地理、生物）碎片化刷题应用。

前端使用静态文件，学习进度保存在浏览器。Cloudflare Pages Functions 通过共用的 D1 数据库处理小四门和双题库套餐兑换。

## 免费练习与兑换

- 每日一题和考点速记开放。每学期每科前 20 道客观题、每科前 2 道主观题可试做。错题本可以查看错误记录。
- 分享每日一题可在当前浏览器每天领取 3 道额外客观题，最多累计 30 道。额外题按领取时选择的学期练习顺序分配。
- 小四门完整版 19.9 元。双题库套餐 29.8 元，同一个码在两个题库分别激活，每站最多两个浏览器。
- 购买单题库后可在首页查看邀请码。三位新买家首次兑换时填同一个邀请码，管理员发放奖励后，可在这里领取另一个题库的兑换码。
- 从已有进度备份导入的题仍可回顾。错题自动复习、填空、周日小测和积分称号由完整版解锁。

## 怎么用

打开 `index.html`（或部署到静态托管后打开首页）：

1. 选年级 + 学期：初一 / 初二 / 初三 × 上学期 / 下学期，共 6 档。
2. 点「开始练习」，按学期自动排好的顺序刷题。年级学期与按学期练习的位置会保存在当前浏览器。
3. 可随机练习、只做未做题，或打开跨学期的错题本、到期复习和收藏题。
4. 每日一题每天轮换一道。展开答题卡后可跳题，长题组每页展示 40 道。查看解析后仍可再次作答。
5. 换网址或设备时，先在原网址的「进度管理」下载备份，再到新网址导入。导入会覆盖新网址在当前浏览器里的记录。
6. 从首页「考点」或「练习模式」下的「考点速记」进入分册复习。可按科目、册次和考点类型筛选，也可搜关键词。每张卡的自测答案和参考来源可展开。

## 全国中考真题

首页独立入口，链接 `/#national`。按科目选择「几分钟短练」或「按原卷练」，可筛选地区、年份。首批含 2026 年福建七科完整扫描卷及参考答案，另有 2024 年湖南、长沙五份精选卷，共 50 道英语阅读、物理和化学题。阅读保留完整文章，原卷图片可显示答案及打印。

新题复用现有作答、收藏和进度备份。已解锁和老用户体验期内可练所有整理题，访客按卷体验前 5 题，英语体验首篇阅读。扫描卷阅览开放。

运行 `python tools/import_national_exams.py <原始资料目录>` 可重新导入，需要 PyMuPDF、Pillow。来源摘要、实际年份、页码和跳过的公式题见 `tools/national-import-manifest.json`。题目和原卷按需加载。

### 英语真题（Claude 录入）

`english-src/papers/<id>.json` 是逐题录入、核对过官方答案并写好解析的英语整卷（听力、看图写话除外）。改完运行 `node tools/build_english.mjs`，会生成 `data/national/<id>.js` 并合并进真题目录。重跑 `tools/import_national_exams.py` 会覆盖目录，之后要再跑一次 `build_english.mjs`。英语在「全国中考真题」里按中考题型练（单选、完形、阅读、七选五、短文填空、情景交际、书面表达）。

## 考点速记

`key-points.html` 从 `data/key-points-<科目>.js` 读取知识卡。册次参照人教版教材，内容参考教育部课标与福建原卷。带真题索引的卡片会标出年份和题号。每张卡独立于选择题练习，打开自测答案无需提交答题记录。

## 主观题提分（材料分析 / 论述 / 简答 / 填空）

首页「主观题提分」卡片，可按科目筛选，题目范围 = 当前年级学期及以前的章节。

- **材料分析 · 论述 · 简答**（`type: essay`）：孩子先在文本框（或本子上）作答，点「对照得分点」，系统按关键词预先勾选命中的得分点，孩子对照意思如实调整后「确认得分」。自评得分率 ≥ 60% 算过关；不到 60% 进错题本，和选择题一样按 1、3、7、14 天复习、参加错题清零。每题都有答题思路、得分点、参考示例（有的话）、解析和出处。草稿在关闭页面前暂存在 sessionStorage。
- **填空速记**（`type: blank`）：题干里 `____` 处直接输入，回车跳下一空，自动判分；每空可配多个可接受写法（如“西域都护|西域都护府”）。
- 会考 / 中考冲刺学期（八下、九上、九下）福建中考真题大题排在最前。
- 一组题做完显示本组小结：作答数、正确率、主观题得分，可一键「重练本组错题」。
- 选择题支持键盘：1–4 / A–D 选择，回车提交、下一题。

题目来源：
- 福建中考真题小问 32 道：历史 2024—2026 年第 29—32 题全部小问（参考答案依福建省教育考试院公布的参考答案，得分点由本应用按答案拆分）；道德与法治 2025 年第 26—29 题、2026 年第 26—27 题（原卷答案页未收录，参考答案按统编教材观点整理，出处已注明）。
- 其余论述 / 简答题按人教版（统编）教材各册核心考点编写，出处写明“依据人教版××册××课编写”；填空题为教材核心概念。

数据文件 `data/subjective-<科目>.js`，紧凑格式（`app.js` 的 `expandSubjective()` 负责展开）：

```js
window.XIAOSIMEN_SUBJECTIVE.lishi = [
  { c: 3, m: '材料分析题', src: '2024年福建中考·历史第29题',
    mat: '材料……', q: '设问……（8分）',
    p: [['得分点文字', 3, '关键词|同义词'], ...],   // 分值合计必须等于题干“（N分）”
    ex: '参考示例（可省）', how: '答题思路（可省）', exp: '解析' },
  { c: 1, b: '公元前____年，秦灭六国，定都____。', a: ['221|前221|公元前221', '咸阳'], exp: '……' },
];
```

- `c` 是章节 id（1 七上 … 6 九下），决定 grade / stage。
- 题目 id 按“科目-z<章>-<序号>”（主观）/“科目-k<章>-<序号>”（填空）在文件内顺序生成，**只在末尾追加新题**，中间插入会让后面的题 id 变化、进度错位。
- `node tests/validate.mjs` 会校验：id 唯一、章节存在、得分点分值合计 = 题干分值、空格数 = 答案数、标准答案能被自己判对、每个得分点的关键词能在得分点原文里命中。

## 自动刷题顺序 buildQueue(stage)

实现位置：`app.js` 里的 `buildQueue(stage, banks, progress)`，配合 `interleave()`、`dueQuestions()`、`applyMode()`。

- **平时**：当前学期新课按人教版章节顺序，四门轮着刷（`interleave`：每门取一道，轮一圈再取下一道，不是一门刷到底）。
- **错题**：答错进错题本，SRS 按 1、3、7、14 天复习，到期（`srs.due <= 今天`）的题优先插进队列最前面；到期答对 stage+1，连续答对 4 次算掌握（`mastered=true`），再答错从头开始（退回第 1 级）。

## 每日打卡、积分与补打

实现位置：`app.js` 的 `checkinStatus()` / `doCheckin()` / `clearWrongList()`，进度存在 `xiaosimen-quiz-v1` 的 `progress.checkin` 里。日期一律按中国日期（UTC+8）。

- **打卡条件**（当天只能打一次）：先完成“错题清零”，再做完当日 20 道新题。首页顶部有打卡卡：今日状态、连续天数、总积分、下个奖励还差多少分（进度条）。
- **错题清零**：开始批量刷题前先订正尚未答对的错题和已到期的复习题。订正中答错或查看解析，该题会回到队尾。提前订正可完成当前任务，之后按原定到期日复习。
- **积分**：打卡 +10；连续打卡第 2 天起每天 +2，封顶 +10（连续 6 天及以上每天打卡 +20）；答对一题 +1；错题订正答对 +2（每题每天只计一次分）；当日新题首答正确率 ≥90% +5，满分 +10；一周 7 天都按时打卡 +30。
- **奖励**：积分 100 / 300 / 600 / 1000 分给称号「坚持者 / 刷题达人 / 小四门学霸 / 满分冲刺者」；连续打卡 3 / 7 / 14 / 30 天给「小火苗 / 周冠军 / 半月坚持 / 月度之星」徽章；达成时轻提示，不打断刷题。
- **补打**：漏打 1 天，次日可以补，条件是当天完成“错题清零 + 40 道新题”（双倍量）；补上后连续天数接上（漏的那天 + 今天都算），打卡分 +10 照常，答题分按实际拿，当天连续天数旁标“已补打”。限制：一次只能补最近漏的 1 天；每月最多补打 3 次；补打的天不计入每周全勤 +30。漏打后次日没补上，连续天数断开。
- **记忆强化**：首页有「今日错题速览」卡片（睡前只看题 + 答案，不计分）；每周日自动出一套 20 道混合小测（本周错题 + 薄弱章节）；正确率 <60% 的章节在首页标红、优先排进次日队列（每章至少做 3 道才统计）；连续答对 5 题给一句小鼓励。同知识点换题暂未实现：题库没有知识点标签，无法做同知识点换题。
- **初二下学期（8-down）**：八下新课后自动回滚复习七年级到八年级地理、生物，备战会考；地理、生物的总复习章（九上/九下章，内容是七、八年级总复习）提前用于会考冲刺。
- **初三（9-up / 9-down）**：地理、生物已考完，自动只留道法、历史。
  - 初三上学期：新课后轻量复习七、八年级道法、历史。
  - 初三下学期：新课后自动进七到九年级道法、历史总复习。
- **每日一题**：`data/daily-questions-xiaosimen.js`，按 `(今天 - startDate) % 题数` 轮换，做完记在 localStorage。
- **今日新题**：从当前学期队列中抽取还未正式作答的题，最多抽当天尚缺的数量。旧题重做与查看解析不计入新题数。当前学期无新题时，可以选择其他学期。

考试时间（福州）：地理、生物在初二下学期会考；道德与法治、历史在初三中考。

## 题库格式

每科一个 `.js` 文件，`window.XIAOSIMEN_BANKS["<科目>"] = { title, examLabel, total, chapters, questions }`。打开首页时并行加载四科题库。题目带 `image: true` 时，在进入该题后加载 `data/figures/<题目 ID>.jpg`。旧版图片脚本保留给切换前已打开的页面。

```js
window.XIAOSIMEN_BANKS["dili"] = {
  title: "地理", examLabel: "初中小四门", total: 55,
  chapters: [{ id: 1, title: "七年级上册 · 地球与地图", count: 15 }],
  questions: [{
    id: "dili-h01-q001", chapterId: 1, chapter: "七年级上册 · 地球与地图",
    number: 1, type: "single", meta: "单选题",
    grade: "七上", stage: "7-up",
    stem: "我国最大的岛屿是（ ）。",
    options: [{ key: "A", text: "海南岛" }, { key: "B", text: "台湾岛" }],
    answer: ["B"],
    explanation: "台湾岛面积约 3.6 万平方千米，是我国第一大岛。",
    trap: "易错点：海南岛是第二大岛。"
  }]
};
```

- `type`（选择题题库）：`single`（单选）、`multiple`（多选，至少选 2 项才能提交，最多选 `maxSelections`，默认 4）、`judge`（判断）。
- 判断题统一用 `answer: ["true"] / ["false"]`，`options` 留空，由渲染合成“正确 / 错误”。
- `total` 必须等于 `questions.length`，`chapters[].count` 必须等于该章实际题数。
- 每题都有 `grade`（如“七上”）和 `stage`（如“7-up”），不要把年级塞进 `meta`；`meta` 是原题型文字。
- 每题都要有 `explanation`；`trap` 是可选易错点。
- 进度 key：`xiaosimen-quiz-v1`（与原应用不同，不会串进度）。

## 域名与发布

Cloudflare Pages 项目 `xiaosimen` 已连接 GitHub 仓库 `beckowen623-ux/xiaosimen`，生产分支为 `main`，启用了自动部署。正式发布时，在生产 D1 的 007、008、009 迁移通过验收并获站长批准后，使用以下 Pages 设置，再推送已批准的版本。

| 后台设置 | 值 |
| --- | --- |
| Build configuration → Root directory | 留空（仓库根目录） |
| Build configuration → Build command | `node tools/stage_pages_release.mjs` |
| Build configuration → Build output directory | `.deploy-pages` |
| Production → Bindings → D1 database | 变量名 `DB`，数据库 `quiz-bank-access` |
| Production → Variables and secrets | `XIAOSIMEN_PAID_LAUNCH_DATE` 为首次收费上线的北京时间日期，格式 `YYYY-MM-DD` |

构建命令会在每次检出后生成发布目录，静态产物包含网页、样式、图片和运行所需的题库 JS。测试脚本和原始资料目录留在源码中。Pages Functions 从仓库根目录的 `functions/` 构建。生产构建设置和 D1 绑定由 Pages 后台管理，仓库的 Wrangler 配置供本地开发使用。[Cloudflare Pages 构建设置](https://developers.cloudflare.com/pages/configuration/build-configuration/) · [Pages Wrangler 配置](https://developers.cloudflare.com/pages/functions/wrangler-configuration/)

本地在仓库根目录运行同一条 Node 命令可复现静态打包。Windows 也可运行 `./tools/stage_pages_release.ps1`，两者调用同一构建脚本。

首次收费上线的日期由站长确认后写入生产变量，后续发布沿用同一天。已有上线日前作答日期的浏览器，首次打开新版后获得 7 天完整版体验，首页显示剩余天数。开始时间单独保存在该浏览器，到期后继续保留练习记录。Cloudflare 的 `main` 构建会检查日期，以免日期缺失时提前发布付费限制。在本地设置相同变量即可演练体验。

Cloudflare Pages 托管仓库中的静态文件，自定义域名为 `x4m.cc.cd`。仍在旧 GitHub Pages 地址练习的同学，可先在原址升级后下载进度备份，再在新域名导入。两处地址由浏览器分别保存进度。

## 原仓库的坑，这里已避开

- `total` 手工数、两处要对上——这里用测试强制校验。
- 题库是 JS 全局变量，文件名 / 全局变量名 / 映射表三者必须一致，否则静默加载失败——这里统一成一个 `XIAOSIMEN_BANKS`。
- 判断题答案格式不统一——这里统一 `true/false`。
- “查看答案”算答对会注水正确率——这里查看答案只记 `done`，不记 `correct`。
- 大文件全量加载——这里按科目拆小文件 + 懒加载。
