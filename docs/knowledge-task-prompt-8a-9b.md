## 上一轮复核发现的问题，这次必须避免
1. **几何题没有配图，条件必须能单靠文字唯一确定。** 初一下学期有一道“双拐点锯齿”题，文字说不清拐点朝向，答案不唯一，已被改掉。初二、初三几何题更多，务必做到：
   - 用明确的数量关系、点的位置（“点 D 在 BC 上”“E 在 AB 的延长线上”）、或坐标描述图形；
   - 需要看图才能判断的情况（角的朝向、点在哪一侧、阴影是哪块），要么在题干写清，要么换一道题；
   - 尺规作图、三视图识图这类离不开图的知识点，改出概念题、步骤判断题、计算题。
2. **数据文件必须和源文件同步。** 上一轮提交里 `data/knowledge-math-7b.js` 与源文件不一致。每次改完源文件都要重新运行 `node tools/build_knowledge.mjs`，把生成的 `data/knowledge-*.js` 一起提交。
3. **每道题先算出答案再写，写完逐题重算。** 涉及根式、方程根、函数解析式、相似比、三角函数值、概率的题，把中间步骤在解析里写完整，确保能复算。
4. **答案是式子的题优先写成选择题**（如函数解析式、因式分解结果、根式化简结果），填空只留答案是单个数的题；填空答案不能含“＞＜≥≤”。
5. 不超纲：每个学期只用该学期及之前学过的知识（例如初二上学期还没学二次根式、勾股定理、一次函数）。特殊角三角函数值只在初三下学期出现。
